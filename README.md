# Controle de Estoque

Aplicação web desenvolvida em React / Next.js para controle de estoque de uma loja consumindo a StockAPI.

## Integrantes da Dupla

- Amanda
- JC

## Como Executar

Instalar as dependências:
```bash
npm install
```

Iniciar o servidor de desenvolvimento:
```bash
npm run dev
```

Acessar no navegador:
http://localhost:3000

## Páginas

- Início: /
- Listar Pedidos: /pedidos
- Criar Pedido: /pedidos/novo
- Produtos: /produtos
- Clientes: /clientes
- Categorias: /categorias
